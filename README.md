# Current Solutions Electrical Services

Next.js 15 website for Current Solutions Electrical Services.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- ESLint
- Framer Motion
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server (Turbopack) |
| `npm run build` | Create a production build |
| `npm run start` | Start the production server |
| `npm run lint` | Run ESLint |

## Deploy

This project is ready to deploy on [Vercel](https://vercel.com). Connect the repository and deploy with the default Next.js settings.
